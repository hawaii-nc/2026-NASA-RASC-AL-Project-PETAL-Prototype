# Project PETAL — Unity VR Prototype

**NASA RASC-AL 2026 Finalist · Project PETAL (UH Mānoa + UH Hilo)**

Unity VR simulation of Project PETAL's lunar surface power architecture, built to visualize the **PMAD (Power Management and Distribution)** system for NASA engineers and judges.

Project PETAL was selected as **1 of 14 finalists from 150+ teams nationwide** and secured $7,000 in award funding. I served as Project Manager, coordinating requirements and integration across energy generation, storage, and distribution subsystems for a scalable lunar power system.

## What This Prototype Shows

- Interactive VR walkthrough of the PETAL power system layout on the lunar surface.
- PMAD system visualization — how power is generated, stored, and distributed across the architecture.

## Running It

This is a Unity project (C#). Clone the repo and open the project folder in Unity Hub / Unity Editor to run the simulation.

## Context

- Competition: NASA Revolutionary Aerospace Systems Concepts — Academic Linkage (RASC-AL) 2026
- Team: University of Hawai'i at Mānoa and University of Hawai'i at Hilo
- Design: Scalable lunar surface power for sustained Moon operations
